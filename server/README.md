# pinedit-mcp

PinEdit 的本机 MCP 服务。浏览器插件把页面上标好的**元素、圈选文字或选区**与修改意见交到这台电脑，Cursor 等开发环境里的 AI 通过 MCP 取走这一批，按意见改代码。

页面上的标注工具是 [PinEdit 浏览器插件](https://github.com/chantezy/pinedit)，需要另外安装。

## 在 Cursor 里启用

放进项目的 `.cursor/mcp.json`，或 Cursor 设置里的 MCP：

```json
{
  "mcpServers": {
    "pinedit": {
      "command": "npx",
      "args": ["-y", "pinedit-mcp"]
    }
  }
}
```

`-y` 是 `--yes`。Cursor 拉起进程时没有地方让你确认安装，少了它，第一次会停在「要不要安装 pinedit-mcp」，服务起不来。

配好之后打开一次对话，服务会跟着起来，并在 `127.0.0.1:4737` 等插件把标注送进来。需要 Node.js 20 或更新。发新版本后在该环境里重连 MCP。

## 一次标注怎么交出去

1. 在页面上点元素、圈选一段文字，或拖出一块区域，写上意见。
2. 点插件工具条上的 PinEdit（火花图标）。剪贴板里只有一句「按 PinEdit 的标注改」。
3. 把这句话贴进当前项目的对话再发送。
4. AI 调用 `pinedit_get_pending` 读取这一批，改代码之前调用 `pinedit_complete`。

同一时间只有一批待读取。上一批还没取走时，再点 PinEdit 会把新加的和这批还没读取的合在一起送出。取走之后队列清空。

插件上的**复制**按钮是另一条路：整份标注进剪贴板，适合还没接 MCP 的对话。

## 工具

### pinedit_get_pending

没有参数。没有待读取的标注时，明确返回空，不要编造。有标注时返回 Markdown 文本，里面带批次 id。

**元素示例：**

```markdown
### 1. button：「开通」
**位置:** `#buy`
**尺寸:** 120×40
**意见:** 加宽到 160
```

**圈选文字示例**（没有元素宽高，多一行说明）：

```markdown
### 2. span：「会员方案」
**位置:** `.title`
**意见:** 改成两行
**说明:** 改的是圈选的这段文字，不是整个元素。
```

**选区示例：**

```markdown
### 3. 区域
**位置:** 页面坐标 120, 80
**尺寸:** 220×72
**意见:** 这里加一条提示
**说明:** 这里要新加一块，页面上没有对应元素。
```

标题里引号中的文字是元素上原有的内容，用来辨认，不是要改写的文案。说明里写了「圈选的这段文字」时，只改用户拖选的那一段。

### pinedit_complete

参数 `batchId` 用 `pinedit_get_pending` 返回里的批次 id。id 对得上才删除本机队列。改代码之前先调用它，避免同一批被重复执行。

## 数据放在哪

只写本机 `~/.pinedit/pending.json`。不上传。插件只访问 `127.0.0.1:4737`。
