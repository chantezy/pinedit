# PinEdit

在浏览器里点中要改的元素，把选择器和真实尺寸交给本地 AI。插件装一次，不用改每个前端项目。

## 组件构成

仓库里有两块，各自独立发布：

| 目录 | 是什么 | 怎么给别人 |
| --- | --- | --- |
| `extension/` | Chrome / Edge 插件，压成 zip 上传商店 | 商店安装 |
| `server/` | 本机 MCP 服务（包名 `pinedit-mcp`） | 发到 npm，用户用 `npx -y pinedit-mcp` |

插件不依赖 npm 包；MCP 服务也可以直接从源码路径跑。发 npm 是为了别人不用克隆这个仓库。

## 怎么用

1. 启动本机服务。Cursor 配好 MCP 后，对话一连上就会把它拉起来。单独开的话：

```bash
cd server && npm start
```

2. Edge 打开 `edge://extensions`，打开开发人员模式，加载 `extension` 文件夹。Chrome 用 `chrome://extensions`，同一套文件。
3. 打开要改的页面再点工具栏里的 PinEdit。本地 html 地址栏会显示「文件」，需要先在扩展详情里勾选「允许访问文件网址」。右下角会出现工具条。改完插件后，在扩展管理页点重新加载。
4. 写意见，按右下角的 PinEdit 按钮（火星图标）发给 AI。这句「按 PinEdit 的标注改」会复制到剪贴板，贴进 Cursor 对话再发送。
5. 本机服务没开时，PinEdit 按钮不出现，标注会留在页面上，不会丢。用复制按钮拿一份 Markdown 也行，贴进任何对话。

## 工具条

一排图标，鼠标停上去才显示名字：

| 图标 | 作用 |
| --- | --- |
| 播放 / 暂停 | 暂停或继续页面上正在循环、或单次超过 1 秒的可见动画。悬停变色和短过渡不算。没有这种动画时置灰，按过暂停才变红 |
| 眼睛 | 隐藏或显示页面上的编号钉和选框。没有标注时置灰 |
| 列表 | 展开标注记录，标题右侧的橡皮清空全部，每条右侧可删除。没有标注时置灰 |
| 复制 | 把这一轮标注复制成 Markdown。没有标注时置灰 |
| 选框 | 切换选区模式，在页面上拖出一块区域。没有标注时仍可用 |
| PinEdit | 浅底、字和图标 #6C6C6C 的主按钮，高度比旁边的图标矮一圈，发给 AI。本机服务没连上或没有标注时置灰 |
| 齿轮 | 设置：颜色、外观、右键关闭、MCP 配置 |
| ✕ | 和左边的按钮隔一条竖线。收起后变成和工具条一样高的圆按钮，落在关闭键的位置。数量为 0 时不显示角标 |

整条工具条 44px 高，阴影收得很浅。按住整条就能拖，拖动不会误触图标。从扩展图标重新打开时回到右下角。点收起时，圆按钮落在关闭键上，页面上的标注先藏起来；再点开，标注和关闭键都回到这个位置。操作结果（已清空、已复制、已交给 AI）出现在页面顶部中间，几秒后自己消失，不再贴在工具条旁边。

## 选区

点选框按钮进入选区模式，然后可以反复拖，每拖一次就在页面上落下一个独立的红色方框：

- 还在选区模式里时，已经落下的框不能拖、不能改大小、不能点开
- 退出选区之后，框可以挪位置，右下角的小方块可以改大小
- 点框才会弹出写意见的弹窗，弹窗里也能看到宽高
- 框右上角的小 ✕ 直接删掉这块，不用进列表
- 写完意见按 Pin，框就变成正式标注，带编号钉。元素悬停框保持实线，不会变成选区那种虚线

选区模式不会自己退出，再点一次选框按钮才关。

## 标注弹窗

- 按住标题行可以把弹窗拖到别处，点一下标题仍展开明细
- 点标题展开元素明细，明细从弹窗上方浮出，弹窗本身不动；上方没空间时改到下方
- 输入框空着时 Pin 置灰，写了意见才能按
- 按 Pin 记下并关闭弹窗
- 右键关闭弹窗。设置里的开关叫「右键关闭标注弹窗」，默认开启

## 两种标注

- 点元素：悬停时框选，点一下弹出卡片，卡片里是 `div "文字"` 和中文样式明细，写完意见按 Pin。
- 拖选区：按选框按钮进入选区模式，按住拖出一块区域，松开弹卡片。区域按页面坐标记录，滚动后仍对齐，发给 AI 时会写明位置和尺寸，用于「这里新加一块」这种需求。

## 设置

- 颜色：七个色点，选中的那个套一圈同色外环
- 外观：默认亮色，也可以切到暗色。点设置面板外面任意位置，面板会收起
- MCP：标题右侧一个小圆点，绿色是已连接，红色是未连接。下面是可直接粘进 MCP 配置的 JSON，右上角的复制按钮只复制那段代码

## 发给 AI 的内容

每条标注交给 AI 时，用元素自己的文字来称呼它，后面是位置、当前宽高和你的意见。意见是要改的内容；宽高只作对照。区域标注则是页面坐标、宽高和意见，表示这里要新加一块。代理读到之后调用 `pinedit_complete`，这批就从本机删掉。下一轮从空页面重新标。

MCP 服务可以走 npm，也可以直接用本机源码：

```json
{
  "mcpServers": {
    "pinedit": {
      "command": "npx",
      "args": ["-y", "pinedit-mcp"]
    }
  }
}
```

上面这段要在 `pinedit-mcp` 发布到 npm 之后才有效。发布前用本机路径这一份（`.cursor/mcp.json` 里就是）：

```json
{
  "mcpServers": {
    "pinedit": {
      "command": "node",
      "args": ["/Users/Fronter/4399/AI/pinedit/pinedit/server/index.js"]
    }
  }
}
```

发布 npm 包（只需一次，之后改版本号再发）：

```bash
cd server
npm login                     # 需要先有 npm 账号
npm publish --access public   # 包名 pinedit-mcp，目前没被占用
```

不发布也完全能用：本机路径、插件、MCP 都是通的，只是别人拿到插件后得自己 clone 仓库。等你要发给别人试、或者上架商店时再发。

代理说明在 `skills/pinedit/SKILL.md`，可放到 Cursor 的技能目录。

## Edge 附加商店

可以上架。这套插件已经按审核习惯收过一遍，但现在还不能直接提交。

已经对齐的部分：

- Manifest V3。Edge 附加商店不收新的 V2。
- 单一用途：给当前页做标注，交给本机 AI。
- 权限只有 `activeTab`、`scripting`、`storage`，外加 `http://127.0.0.1:4737/*`。不申请全站权限，只有你点了图标的那个标签页才会注入。
- 没有远程代码，字体和图标都在包里。
- 数据只进本机文件。隐私说明在 `store/PRIVACY.md`。

提交前还要补：

- 注册 [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/public/login) 的 Edge 扩展开发者账号。
- 商店描述至少 250 字，短说明用 manifest 里的 `description`，改文案就要重新传 zip。
- 图标用 `store/logo-300.png`（300×300）。截图要 1280×800 或 640×480，最多 6 张，需要你在 Edge 里实际标一次再截。
- 隐私页要填：单一用途、每个权限的理由、声明没有远程代码、数据用途。因为会读取页面上的文字和地址，需要一个公网可打开的隐私政策链接，把 `store/PRIVACY.md` 放到你自己的页面上。
- 打包时只压 `extension` 目录：`cd extension && zip -r ../store/pinedit-0.1.0.zip . -x '*.DS_Store'`

权限理由可以照这几句填：

| 权限 | 理由 |
| --- | --- |
| activeTab | 只在用户点工具栏图标时，进入当前标签页 |
| scripting | 把标注层注入当前页 |
| storage | 在发给 AI 之前，记住这一轮还没提交的标注 |
| 127.0.0.1:4737 | 只把用户点过 PinEdit 按钮的那一批发给本机 MCP |
