# PinEdit

在浏览器里标注要改的地方：点元素、圈选一段文字，或拖出一块选区，把选择器、尺寸和意见交给本地 AI。插件装一次，不用改每个前端项目。

## 组件构成

仓库里有两块，各自独立发布：

| 目录 | 是什么 | 怎么给别人 |
| --- | --- | --- |
| `extension/` | Chrome / Edge 插件，压成 zip 上传商店 | 商店安装 |
| `server/` | 本机 MCP 服务（包名 `pinedit-mcp`） | 发到 npm，用户用 `npx -y pinedit-mcp` |

插件不依赖 npm 包；MCP 服务也可以直接从源码路径跑。发 npm 是为了别人不用克隆这个仓库。

产品介绍与文档站单独维护，不在本仓库。本地与 `website/` 并列；公开可另建 `pinedit-website` 仓。

## 怎么用

1. 启动本机服务。Cursor 配好 MCP 后，对话一连上就会把它拉起来。单独开的话：

```bash
cd server && npm start
```

2. Edge 打开 `edge://extensions`，打开开发人员模式，加载 `extension` 文件夹。Chrome 用 `chrome://extensions`，同一套文件。
3. 打开要改的页面，点浏览器工具栏里的 PinEdit 图标。本地 html 地址栏会显示「文件」，需要先在扩展详情里勾选「允许访问文件网址」。右下角会出现工具条。改完插件后，在扩展管理页点重新加载。
4. 点元素写意见，或按住拖过一段文字弹出标记窗，或进入选区模式拖出一块区域。按 Pin 记在页面上。
5. 本机 MCP 连上时，点工具条上的 PinEdit（火花图标）发给 AI，剪贴板里会有一句「按 PinEdit 的标注改」，贴进对话再发送。服务没连上时用复制按钮拿整份 Markdown，贴进任意对话。

## 工具条

一排图标，鼠标停上去才显示名字：

| 图标 | 作用 |
| --- | --- |
| 播放 / 暂停 | 暂停或继续页面上正在循环、或单次超过 1 秒的可见动画。悬停变色和短过渡不算。没有这种动画时置灰，按过暂停才变红 |
| 眼睛 | 隐藏或显示页面上的编号钉和选框。没有标注时置灰 |
| 列表 | 展开标注记录，标题右侧的橡皮清空全部，每条右侧可删除。没有标注时置灰 |
| 复制 | 把这一轮标注复制成 Markdown。没有标注时置灰 |
| 选框 | 切换选区模式，在页面上拖出一块区域。没有标注时仍可用 |
| PinEdit | 浅底、字和图标 #6C6C6C 的主按钮，高度比旁边的图标矮一圈，发给 AI。本机服务没连上或没有标注时置灰 |
| 齿轮 | 设置：颜色、外观、右键关闭、MCP 配置 |
| ✕ | 和左边的按钮隔一条竖线。收起后变成和工具条一样高的圆按钮，落在关闭键的位置。数量为 0 时不显示角标 |

整条工具条 44px 高，阴影收得很浅。按住整条就能拖，拖动不会误触图标。从扩展图标重新打开时回到右下角。点收起时，圆按钮落在关闭键上，页面上的标注先藏起来；再点开，标注和关闭键都回到这个位置。操作结果（已清空、已复制、已交给 AI）出现在页面顶部中间，几秒后自己消失，不再贴在工具条旁边。

## 选区

点选框按钮进入选区模式，然后可以反复拖，每拖一次就在页面上落下一个独立的红色方框：

- 还在选区模式里时，已经落下的框不能拖、不能改大小、不能点开
- 退出选区之后，框可以挪位置，右下角的小方块可以改大小
- 点框才会弹出写意见的弹窗，弹窗里也能看到宽高
- 框右上角的小 ✕ 直接删掉这块，不用进列表
- 写完意见按 Pin，框就变成正式标注，带编号钉。元素悬停框保持实线，不会变成选区那种虚线

选区模式不会自己退出，再点一次选框按钮才关。

## 标注弹窗

- 按住标题行可以把弹窗拖到别处，点一下标题仍展开明细
- 点标题展开元素明细，明细从弹窗上方浮出，弹窗本身不动；上方没空间时改到下方
- 输入框空着时 Pin 置灰，写了意见才能按
- 按 Pin 记下并关闭弹窗
- 弹窗开着时，点页面空白不会关掉，窗口会抖一下
- 右键关闭弹窗。设置里的开关叫「右键关闭标注弹窗」，默认开启

## 三种标注

- **点元素**：悬停时框选，点一下弹出卡片，卡片里是元素描述和样式明细，写完意见按 Pin。
- **圈选文字**：在页面上按住拖过一段文字，弹出同样的标记窗。输出里会写明只改圈中的这句，不会误改整个元素；明细以字号、字重、字色为主，不带整块元素的宽高。
- **拖选区**：按选框按钮进入选区模式，按住拖出一块区域，松开弹卡片。区域按页面坐标记录，滚动后仍对齐，发给 AI 时会写明位置和尺寸，用于「这里新加一块」这种需求。

## 设置

- 颜色：七个色点，选中的那个套一圈同色外环
- 外观：默认亮色，也可以切到暗色。点设置面板外面任意位置，面板会收起
- MCP：标题右侧一个小圆点，绿色是已连接，红色是未连接。下面是可直接粘进 MCP 配置的 JSON，右上角的复制按钮只复制那段代码

## 发给 AI 的内容

每条标注交给 AI 时，用元素自己的文字来称呼它，后面是位置、当前宽高和你的意见。圈选文字会多一行说明，只改引号里的那段。区域标注则是页面坐标、宽高和意见，表示这里要新加一块。上一批还没取走时，再发送会连同这批还没读取的一起交出去。代理读到之后调用 `pinedit_complete`，这批就从本机删掉。

## 发版（Edge / 本地 zip / GitHub）

**以后更新插件，只打包 `extension/` 目录**，不要带仓库里的其他文件夹。版本号改 `extension/manifest.json` 的 `version`，然后：

```bash
node scripts/package-extension.mjs
```

默认会在 `../website/store/pinedit-<版本>.zip` 生成安装包（仅本地打包用；GitHub 用 Release 上传同名的 zip）。Edge 商店后台也是上传这一份 zip。

MCP 服务改在 `server/` 里发 npm：`cd server && npm publish`（先跑测试、改 `package.json` 版本）。

用 npm 上的 `pinedit-mcp`。`-y` 用来跳过第一次安装确认，Cursor 拉起进程时没有地方输入 `y`：

```json
{
  "mcpServers": {
    "pinedit": {
      "command": "npx",
      "args": ["-y", "pinedit-mcp"]
    }
  }
}
```

改完服务发一版，各台机器重连 MCP 就会用到新包。

服务读到的文本、两个工具和队列规则写在 `server/README.md`，也是 npm 页面上的说明。代理步骤在 `skills/pinedit/SKILL.md`。

## Edge 附加商店

**当前状态：** [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/public/login) 已提交 **0.1.1**，审核通过后商店会自动向已安装用户推送。本地 zip 与 GitHub Release 见上文「发版」。

**下次改插件要上架时：**

1. 改 `extension/manifest.json` 的版本号，执行 `node scripts/package-extension.mjs`。
2. 把生成的 `pinedit-<版本>.zip` 上传到 Partner Center 新版本，并同步 [GitHub Releases](https://github.com/chantezy/pinedit/releases)（附件名与 manifest 一致）。
3. 若改了 `description` 或权限，商店文案/隐私说明也要一起改，否则可能被拒。

商店素材约定（首版已填过，大改时再核对）：

- 图标：官网仓库 `store/logo-300.png`（300×300，`node scripts/make-icons.mjs` 会生成到那里）。
- 截图：1280×800 或 640×480，最多 6 张。
- 隐私政策：公网链接指向官网上的说明（源文件 `website/store/PRIVACY.md`）。
- 合规要点：Manifest V3、单一用途（页面标注交给本机 AI）、无远程代码、数据仅本机 MCP；权限见下表。

权限理由（Partner Center 可照抄）：

| 权限 | 理由 |
| --- | --- |
| activeTab | 只在用户点工具栏图标时，进入当前标签页 |
| scripting | 把标注层注入当前页 |
| storage | 在发给 AI 之前，记住这一轮还没提交的标注 |
| 127.0.0.1:4737 | 只把用户点过 PinEdit 按钮的那一批发给本机 MCP |
