# PinEdit

用户在 Edge 或 Chrome 里用 PinEdit 点选元素，或者拖出一块区域。每一条用元素自己的文字来称呼它，并给出位置、当前宽高和用户写的意见。意见是要改的内容。

## 怎么做

1. 调用 `pinedit_get_pending`。
2. 没有标注就停下来，告诉用户先在浏览器里标注并点右下角的 PinEdit 按钮。
3. 有标注时，先调用 `pinedit_complete`，参数 `batchId` 用返回里的批次 id。取走之后再改代码。
4. 按「位置」找到源码，只改「意见」里写的那一点。标题里的文字是这个元素自己的内容，用来辨认，不是要你重写的文案。宽高只用来对照现在的大小，不要把没提到的内边距、字号、颜色、圆角抄进样式。
5. 「区域」没有对应元素，只有页面坐标和宽高。它表示「这里要新加一块」，照着坐标和尺寸找插入位置和大致高度。
6. 说明里写了「改的是圈选的这段文字」时，引号里的原文是用户拖选的那一段。只改这一段，同一个元素里没被圈到的字不要动。
7. 不要编造标注里没有的修改。空意见只说明用户点了这个元素。
